Required contracts

Architecture surfaces to make build-ready

World primitives

Entity, Fact, Representation, Operation schemas and ownership.

Graphlets

Identity, composition, overlap, boundaries and stable references.

Operations + patches

Typed inputs, READS/WRITES, candidate patches and commit semantics.

Dependencies

Invalidation, dirty state, lazy recomputation and failure propagation.

Representations

Authority metadata, resolution, provenance, exact/derived/observed states.

Spatial query

BVH/R-tree/octree/tile routing from point or region to relevant world state.

Revision + branch

Immutable revisions first; fork and richer branching only when earned.

Constraints

Procedural checks first, Z3/SMT behind a typed interface when justified.

Projection boundaries

Three.js, USD, specialist solvers and imports as projections/proposals.

Persistence

Storage interfaces without leaking database choice into world semantics.

Language boundaries

TypeScript world/app, C++ exact geometry, Python experimentation via coarse typed IPC.

Failure semantics

DIRTY, CLEAN, FAILED, STALE, UNKNOWN and local containment rules.
