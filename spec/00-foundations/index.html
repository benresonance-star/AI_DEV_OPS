PLASMA-FOUNDATIONS-001 · Canonical

Foundations

The small, slow-changing rules that every world model, architecture contract, capability and engineering agent must preserve.

CanonicalSlow-changing
Core law

One concept, one identity

Every important concept has one authoritative definition and one stable identifier. References never create alternative versions of the concept they reference.

State discipline

Proposals are not canonical state until validated and committed.

Authority discipline

Exact geometry is authoritative only for exact-geometry questions; other truths retain their own authority.

Agent discipline

LLMs and agents interpret and propose. They do not own technical truth.

Identity discipline

Representations are replaceable; stable identity persists.

Complexity discipline

Complexity must be earned by a capability, correctness requirement or measured bottleneck.

Reference discipline

Define once. Reference everywhere. Resolve conflicts explicitly.
